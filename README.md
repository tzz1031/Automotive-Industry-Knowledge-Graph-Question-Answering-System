# 汽车工业知识图谱问答系统

一个基于知识图谱的汽车行业智能问答系统，整合了**全球汽车产业数据**和**前沿汽车技术**两大知识体系，提供技术查询、车型对比、供应链分析等专业问答服务。

## 📊 系统概览

| 模块 | 数据量 | 说明 |
|------|--------|------|
| 车型数据 | 100+ 款 | 涵盖比亚迪、小米、蔚来、理想、小鹏、宝马等主流品牌 |
| 技术实体 | 338 个 | ADAS系统、电池技术、车规芯片、传感器等 |
| 属性条目 | 277 条 | 技术参数、规格指标等 |
| 关系三元组 | 217 条 | 企业-技术、技术-技术间的关联关系 |

## ✨ 核心功能

### 1. 技术知识问答
- **技术分类查询**：「有哪些ADAS系统？」「有哪些电池技术？」
- **技术参数查询**：「C-Pilot 5.0的算力是多少？」「M3激光雷达的测距能力？」
- **企业技术研发**：「华为研发了哪些技术？」「奇瑞发布了哪些技术？」

### 2. 车型信息查询
- **车型详情**：「小米SU7参数」「蔚来ES8配置」
- **车型对比**：「小米SU7和蔚来ES8对比」
- **技术配置筛选**：「有激光雷达的纯电SUV有哪些？」

### 3. 供应链分析
- **供应商查询**：「宁德时代供应哪些车？」
- **零部件追溯**：「哪些车用了Orin芯片？」「哪些车用了骁龙8295？」

### 4. 数据统计
- **技术分类统计**：「统计技术分类」
- **车型价格分布**、**能源类型分布**

### 5. 行业宏观数据
- 2024年全球/中国汽车产销数据
- 新能源车渗透率、出口数据、竞争格局
- 企业销量排名、市场份额变化

## 🚀 快速开始

### 前置要求

- **Python 3.9+**
- **Neo4j 数据库**（本地或云端）
- 推荐使用 Docker 快速启动 Neo4j：

```bash
docker run -d \
  --name neo4j-auto \
  -p 7474:7474 -p 7687:7687 \
  -e NEO4J_AUTH=neo4j/12qwaszx \
  -e NEO4J_PLUGINS='["apoc"]' \
  neo4j:5.26-community
```

### 安装依赖

```bash
pip install -r requirements.txt
```

`requirements.txt` 内容：
```
neo4j>=5.0.0
pandas>=2.0.0
numpy>=1.24.0
requests>=2.31.0
openai>=1.0.0
python-docx>=1.0.0
fitz>=0.0.1
pdfplumber>=0.10.0
```

### 导入数据

```bash
cd graphBuild
python import_all.py
```

### 启动问答界面

#### 本地 JSON 模式（无需 Neo4j）

```bash
cd graphBuild
python web_ui.py
```

访问 `http://localhost:8888`

#### Neo4j 模式（推荐）

```bash
cd graphBuild
python qa_neo4j.py
```

命令行交互式问答。

## 📖 知识图谱数据模型

### 节点类型

| 标签 | 说明 | 示例 |
|------|------|------|
| `Car` | 车型节点 | 小米SU7、蔚来ES8 |
| `Brand` | 品牌节点 | 比亚迪、宝马 |
| `Series` | 车系节点 | 宋Pro DM、宝马3系 |
| `Technology` | 技术实体 | ADS 3.0、麒麟电池、Orin芯片 |
| `Supplier` | 供应商 | 宁德时代、英伟达 |
| `Motor` | 电机实体 | 永磁同步电机 |
| `Battery` | 电池实体 | 磷酸铁锂电池包 |

### 主要关系

| 关系类型 | 说明 |
|----------|------|
| `BELONGS_TO_BRAND` | 车型归属品牌 |
| `HAS_MOTOR` / `HAS_BATTERY` | 车型配备 |
| `USES_BATTERY_CELL` / `USES_ADAS_CHIP` | 供应链关系 |
| `DEVELOPED_BY` / `PUBLISHED` | 技术研发关系 |
| `SUPPORTS` / `EQUIPPED_WITH` | 技术能力关系 |

## 🛠️ 自定义扩展

### 添加新车型数据

编辑 `data/car_data/car_data.json`，遵循现有格式：

```json
{
  "car_id": "xxx",
  "car_name": "车型名称",
  "brand_name": "品牌",
  "price_wan": 19.99,
  "energy_category": "BEV",
  "range_km": 600,
  "has_lidar": true
}
```

### 添加新技术实体

编辑 `data/car_data/car_entity.json`：

```json
{
  "entity_name": {
    "type": "entity",
    "category": "BatteryTechnology",
    "attributes": {"能量密度": "200Wh/kg"},
    "relations": [
      {"relation": "研发企业", "object": "企业名称"}
    ]
  }
}
```

### 运行评测

```bash
python eval/eval.py --cases eval/cases.json --output report.json
```
